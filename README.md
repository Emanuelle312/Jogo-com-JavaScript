# Jogo de Adivinhação de Palavras

Projeto desenvolvido na disciplina de Desenvolvimento de Aplicações Web I (IFPB - Campus Campina Grande).

## Integrantes

- Nome do aluno 1
- Nome do aluno 2 (se houver)

## Como jogar

Digite uma letra e clique em Tentar (ou pressione Enter). O objetivo é descobrir a palavra antes de acabar as tentativas.

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Funcionalidades

- Palavra aleatória (12 palavras possíveis)
- Controle de tentativas
- Letras utilizadas, com bloqueio de letras repetidas
- Mensagens de vitória e de derrota (revela a palavra)
- Reinício da partida
- Extras: dicas por palavra, envio com Enter, placar de partidas/vitórias/derrotas e animação de erro
